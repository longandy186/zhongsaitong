# 选举活动：Fico未出席SNS集会，Novi Pazaru的学生名单

距离塞尔维亚选举还有22天，竞选活动正在加速和加剧。10月3日，执政的塞尔维亚进步党在贝尔格莱德的阿雷纳举办了一个大型集会，同时Novi Pazaru的学生名单也在塞尔维亚西南部城市举办集会。尽管宣布斯洛伐克总理Robert Fico将作为特别嘉宾出席，但他最终没有到达贝尔格莱德。由于健康原因，他无法乘坐飞机旅行。集会上将宣读他的讲话。在阿雷纳前面的平台上聚集了很多人，大多数穿着写有“统一塞尔维亚”的白衬衫，BBC的Slobodan Maričić报道说，附近停放着许多SNS支持者乘坐的公交车。前塞尔维亚总统Aleksandar Vučić宣布了另一位特别嘉宾，斯洛伐克总理Robert Fico，他强调Fico一直支持塞尔维亚的欧洲道路，并对俄罗斯联邦持平衡态度。塞尔维亚在2022年乌克兰入侵后没有对俄罗斯实施制裁，并采取在国际关系中坐在多个席位上的政策。俄罗斯总统Vladimir Putin支持Vučić，并表示希望他将成为总理。尽管很少就国际问题发表声明，但学生名单“学生胜利”也宣布反对对俄罗斯实施制裁。当SNS的支持者在贝尔格莱德集会时，在塞尔维亚首都270公里外的Novi Pazaru，学生名单组织了预选集会。Novi Pazaru是一个以波斯尼亚人为主的城镇，自南斯拉夫解体和族间紧张关系以来，波斯尼亚人作为少数族裔在塞尔维亚经常受到歧视。正是在这个城市的学潮期间，许多年轻人表示他们第一次感觉到自己是塞尔维亚公民。名为“3对3”的集会将在市中心举行，组织者宣布了演讲者名单，其中包括学生名单的人。塞尔维亚社会主义党在同一天在Smederevo组织了预选集会。还举行了一场电视辩论，参与者包括Ana Brnabić、Vladan Kuzmanović、Dunja Simonović Bratić和Marinika Tepić。在国外的报名截止日期是10月3日凌晨。塞尔维亚共和国选举委员会的Sofija Mandić表示，侨民报名人数创下纪录。到目前为止，已有约75,000人报名，而上次选举时为39,000人，投票人数约为30,000人。SNS和塞尔维亚社会主义党SPS之间的不稳定性似乎在增加。Vučić告诉SPS副主席Novica Tončev，政治不是交易，他不会接受妥协，并表示“与这种做法已经结束”。他说：“我不要求你们，自由地与他们一起去，因为你们现在是我的人，在这些日子里，你们已经表明你们没有任何想法和意识形态，没有计划和方案，你们是商人。”他说：“等待选举结束，然后我们再看看。”BBC塞尔维亚语现在也在TikTok上，请在这里关注我们。在Facebook、Twitter、Instagram、YouTube、Viber上关注我们。如果您有主题建议，请发送至[email protected]。
