# OpenAI 将向乌克兰提供最先进的网络安全人工智能工具

美国人工智能公司 OpenAI 今日在联合国大会期间宣布，将向乌克兰提供基于人工智能的最先进网络安全工具的访问权限。这些工具旨在帮助乌克兰识别并消除潜在的安全漏洞。这一举措是在乌克兰总统弗拉基米尔·泽连斯基出席大会期间宣布的，旨在加强乌克兰的网络安全防御能力。
