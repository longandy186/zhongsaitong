# 俄罗斯决定剥夺亚美尼亚在 Collective Security Treaty Organization (ODKB) 的投票权

俄罗斯总统新闻秘书佩斯科夫表示，由于亚美尼亚连续多年未履行对集体安全条约组织（ODKB）的义务，决定剥夺其投票权。俄罗斯外交部长拉夫罗夫此前表示，俄罗斯无意将亚美尼亚排除出ODKB。

拉夫罗夫指出，根据协议第25条，如果对ODKB预算的欠款超过两年，国家将失去投票权。亚美尼亚总理帕希尼亚安表示，亚美尼亚可能在2027年或2028年正式申请加入欧盟。

帕希尼亚安表示支持将亚美尼亚从ODKB中排除，并表示如果这一决定得以实现，他将感到满意。自2024年初以来，亚美尼亚未向ODKB预算缴纳会费，帕希尼亚安此前宣布，亚美尼亚已冻结在该组织中的参与。他称，这一决定的原因是纳戈尔诺-卡拉巴赫冲突，声称至少有两个ODKB成员国帮助阿塞拜疆为对亚美尼亚的战争做准备，同时仅对埃里温提供象征性的援助。

帕希尼亚安没有指明具体的国家，但表示当时的军事行动旨在消除亚美尼亚的独立性。俄罗斯外交部发言人扎哈罗娃提醒，ODKB在2022年9月迅速组建了一个评估小组，并派往亚美尼亚边境地区。评估小组的报告后，集体安全理事会决定在亚美尼亚部署观察小组，但耶路撒冷的当局拒绝了这一提议，并决定邀请欧盟代表。
