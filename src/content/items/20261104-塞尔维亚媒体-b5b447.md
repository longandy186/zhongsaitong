# 塞尔维亚官员Bajatović解释访问俄罗斯原因

塞尔维亚Srbijagas公司董事Dušan Bajatović在接受N1采访时表示，在飞机从莫斯科返回贝尔格莱德机场后，对所有乘客和行李进行了详细的安全检查。

Bajatović指出，尽管飞机上有Aleksandar Vulin和Nenad Popović，但他不清楚他们访问俄罗斯的原因。他自己的访问与天然气供应谈判和Alta银行支付问题有关。

Bajatović提到，飞机在抵达贝尔格莱德后，他被通知必须通过全新的安全程序，所有行李都进行了详细检查。
