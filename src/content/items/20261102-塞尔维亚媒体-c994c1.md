# Mitrović裁员应对亏损

Pink Media Group老板Mitrović宣布解散Odeon剧院并解雇150名员工，预计还将有更多员工被裁。Mitrović在议会选举失败后宣布缩减其媒体帝国的规模，预计将有约一千名员工失业。Mitrović被认为是塞尔维亚最富有的人之一，也是媒体界的重要人物。据经济登记局的数据，2022年和2023年，Mitrović的净收入分别为28百万欧元。2022年，Mitrović的净收入为1.659.583.000第纳尔，约合1400万欧元；2023年，净收入为1.644.786.000第纳尔，约合1400万欧元。

然而，2024年，Mitrović的净收入大幅下降至186.555.000第纳尔，约合100万欧元。2025年，情况略有改善，净收入约为644.754.000第纳尔，约合500万欧元。Odeon剧院，Mitrović的私人剧院，仅存在了两年零一个月，位于著名的“Odeon”电影院，拥有880个座位，面积2.524平方米。Odeon剧院于2024年9月13日开业，上演了《Lucifer》。然而，剧院仅实现了8场首演。

Odeon剧院的官方财务报告显示，剧院在2024年的收入仅为15.2百万第纳尔，而支出为138.6百万第纳尔，最终亏损123.4百万第纳尔。根据APR的数据，去年Teatar Odeon在工资、税收和福利方面的支出为115.1百万第纳尔，近100万欧元。

Mitrović与SNS和前总统Vučić的关键人物有联系。据媒体报道，塞尔维亚政府多年来通过数百万欧元的贷款、担保和推迟税收债务来帮助Pink Media Group。CINS发现，Pink从国家机构AOFI获得了至少128亿第纳尔（超过1000万欧元）的出口信贷和担保。尽管AOFI根据法律仅应资助没有税收债务的成功出口商，但国家在Pink成为国家最大的税收债务人的年份批准了这些数百万欧元的款项。

Mitrović声称，他定期获得资金，因为TV Pink和他的航空公司在出口节目和服务方面实现了巨大的外汇流入。Mitrović在学生名单代表Nemanja Karović在RTS表示，Telekom的资金仅用于“顺从的、政治上相似的媒体”后，决定采取这样激进的措施。

Telekom与Mitrović的Pink Media Group签订了合同，支付了约700万欧元，仅用于分发55个Pink频道。2023年夏天，Telekom Srbija正式收购了移动运营商Globaltel的100%股份，Globaltel的多数股东（55%）是Mitrović的Pink Media Group。Mitrović在BH Telecom终止了13年的合作后失去了230,000户家庭的市场。可以得出结论，Vučič政府的倒台有充分的理由影响了Mitrović帝国的市场。
