# Miroslav Talijan任Pink Media Group安全部门副主席

前72特种作战旅指挥官Miroslav Talijan已加入Pink Media Group，担任安全部门副主席。他于今年11月初退休。

Talijan表示，他的任务是确保公司的人、物和信息安全，提供业务风险预警，应对公司面临的所有安全挑战，并确保安全系统的专业性和高效运作。

Talijan是电视节目主持人Suzane Mančić的女婿，他的女儿Teodora去年与比她大23岁的Miroslav结婚，并生有一子。这是Talijan的第六个孩子，他已有两次婚姻。

Talijan强调，他将致力于最大程度地维护纪律，确保公司安全部门的运作符合最高标准。
