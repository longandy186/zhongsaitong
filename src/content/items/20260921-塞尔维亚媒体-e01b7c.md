# 塞尔维亚自由公民运动成员Vladimir Pajić相信SNS将被从EPP中除名

塞尔维亚自由公民运动（PSG）成员Vladimir Pajić表示，相信塞尔维亚进步党（SNS）将在被启动程序后从欧洲人民党（EPP）中被除名。Pajić称SNS是一个反民主和腐败的政治组织，已经不属于欧洲政党家族。他强调，SNS在欧洲的承诺背后隐藏着破坏民主、机构和欧洲价值观的政权。Pajić还提到，在索菲亚的“欧盟与巴尔干会议”上，他呼吁SNS不应在EPP中寻求位置，并强调塞尔维亚应在欧盟中占有一席之地。他还表示，如果真的希望塞尔维亚加入欧盟，那么SNS不应再受到欧洲保护伞的保护。
