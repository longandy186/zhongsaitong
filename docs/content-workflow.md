# 中塞通 · 内容生产自动化工作流（单人运营 SOP）

> 原则：**除「审核、发布、删除」外全部自动化**。
> 你在 WorkBuddy 里每天投入 20-30 分钟，其余由 AI + 自动化完成。

## 一、整体流水线

```
原材料                       AI 处理（WorkBuddy）              审核                 发布
──────────────────────────────────────────────────────────────────────────────────────────
新闻链接 / 塞尔维亚语原文  →  ① 翻译转写        →  本地构建预览   →  用户确认后  →  GitHub push
群消息 / 朋友圈截图        →  ② 去重 + 归类      →  (你看到成品)       │        →  Cloudflare Pages
分类站抓取(4zida等)       →  ③ 打标签 + 生成     →                 │            →  自动上线
用户投稿表单              →  ④ 生成 .md + 配图   →                 │
                                                              ↓
                                                        用户拒绝 → 打回修改 / 弃稿
```

**你要做的只有三件事**：
1. **审核**：看 AI 生成的成品，确认没问题
2. **发布**：说"发布"即可（AI 推送到 GitHub 自动上线）
3. **删除/下线**：说"下线 XXX"，AI 把该条 status 改为 expired

## 四、AI 生成规范（每条信息）

### 信息条目 frontmatter 模板

```markdown
---
title: 泽蒙区 二室一厅 带家具出租   # 中文标题，突出关键信息
category: rentals                  # rentals | secondhand | jobs | news | guide | supply
kind: news                         # 仅新闻用：embassy(使馆) | chamber(商会) | news(要闻)
price: 700€/月                     # 有价格必填，格式统一
location: 新贝·泽蒙                # 位置
date: 2026-08-19                   # 当天日期
contact: 微信 xxx                  # 联系方式（注意脱敏策略，见下）
images:                            # 1-3 张，第一张用于卡片
  - /images/xxx.jpg
tags: [租房, 带家具]
source: 4zida.rs                   # 必填：来源标注
promoted: false                    # 付费推广项才置 true
featured: false                    # 重要置顶才置 true
---
正文（Markdown，简洁，突出关键点）
```

### 标题规范
- 租房：`[区域] [户型] [关键词]`，如 `新贝 二室一厅 带家具出租`
- 二手：`[成色] [物品] [备注]`，如 `九成新 冰柜转让 超市自用`
- 招聘：`[公司] 招聘[岗位]`，如 `中塞合资公司 招聘采购助理`
- 新闻：完整标题即可
- 供求：`[求购/供应] [品类] [用途]`
- 指南：`[主题]指南`

### 内容规范
- 正文 100-300 字，分点列出关键信息（价格/位置/时间/条件）
- 塞语信息必须标注 `source` 和"翻译仅供参考，详情查看原文"
- 重要政策/使馆信息：保留原文链接，核对后再发

### 联系方式脱敏策略
- **默认不把微信/手机号直接放详情页正文**
- 展示方式：`联系方式：微信 xxx`（详情页显示）
- 用户投稿的联系方式按投稿者要求处理

## 三、每日运营节奏（建议）

> 采集是自动的，你每天只需要做**审核 + 确认发布**。

| 时间 | 动作 | 耗时 |
|------|------|------|
| 9:00 | 对我说"今天采集了什么" → 我列出待审核清单 → 你审阅 → "发布第1、3、5条" | 10 分钟 |
| 14:00 | 处理微信群/投稿信息，穿插临时重要信息 | 5-10 分钟 |
| 20:00 | 汇总当天精华 → 生成公众号推送内容 → 你后台发布 | 5 分钟 |
| 每周 | 1 次指南/深度内容；1 条视频号脚本 | 30 分钟 |

**公众号**：每天从当天信息里挑 3-5 条精华，AI 生成图文，你在公众号后台点发布。
**视频号**：AI 生成 1 分钟口播脚本 + 配图，你拍/录或 AI 生成短视频后发布。

### 审核指令示例

- "列出待审核" → AI 展示 pending 清单
- "发布 1 3 5" 或 "全部发布" → AI 把对应文件 status 改为 active 并 push
- "下线 XX" → AI 改 status 为 expired
- "删除 XX" → AI 删除文件

## 六、审核清单（发布前 10 秒检查）

- [ ] 标题信息准确、无夸大
- [ ] 价格/位置/时间正确
- [ ] 联系方式有效
- [ ] 来源已标注（转载/翻译类必须）
- [ ] 图片清晰、非广告图
- [ ] 无敏感内容（涉及中塞关系/政策的，以官方口径为准）

## 七、下线 / 删除操作

- **下线某条**："下线 [标题关键词]" → AI 把该文件 `status` 改为 `expired`
- **彻底删除**："删除 [标题关键词]" → AI 删除该 .md 文件
- 过期内容建议用 `expired`（保留记录，前端不展示），不要急着删

## 八、自动化程度说明

| 环节 | 自动化程度 | 说明 |
|------|-----------|------|
| 信息采集 | **全自动** | GitHub Actions 定时抓取（每天 3 次），见信息源清单 |
| 翻译转写 | 全自动 | AI 完成（GLM-4-Flash 免费） |
| 归类打标 | 全自动 | AI 完成 |
| 生成稿件 | 全自动 | AI 生成 .md（status: pending，默认不展示） |
| 本地预览 | 全自动 | AI 构建预览 |
| **审核** | **人工** | **你确认 pending → active** |
| **发布** | **人工触发** | **你说"发布"，AI 执行 push** |
| 自动部署 | 全自动 | Cloudflare Pages 自动构建上线 |
| **删除/下线** | **人工触发** | **你说，AI 执行** |

> 为什么发布也保留人工触发？—— 一条信息上线即面向全部华人，保持你的控制权，避免 AI 误发。将来内容量大了，可对"低风险类目"（如资讯转载）开启自动发布白名单。
